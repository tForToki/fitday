# Fitday

Fitday is a private, offline-first fitness companion. Data is stored locally in the browser.

## Deploy to GitHub Pages

1. Create an empty GitHub repository.
2. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Push the `main` branch. The included workflow deploys the app automatically.
4. When the workflow finishes, open the URL shown under **Actions → Deploy to GitHub Pages** on your phone.

On iPhone, open the site in Safari, tap Share, then choose **Add to Home Screen**. On Android, open it in Chrome and select **Install app**.
